# Как играть со смартфона

Игра — обычное консольное приложение на C++, поэтому на Android ей нужен
только компилятор и терминал. Проще всего это даёт **Termux**.

## Чем собирать

Подходят оба варианта, разница в удобстве.

| | Termux | C4Droid |
|---|---|---|
| Сборка | `make`, как на компьютере | `make` из встроенной консоли |
| Компилятор | clang (свежий) | GCC из плагина (часто старый) |
| Запуск бинарника | откуда угодно | `/sdcard` смонтирован `noexec` — нужен обходной шаг |
| Обновление | `git pull` | копировать файлы вручную |

Коду достаточно **C++11**, так что старый GCC из C4Droid его собирает.
Ниже сначала Termux, потом C4Droid — раздел [«Сборка в C4Droid»](#сборка-в-c4droid).

## Шаг 1. Поставить Termux правильно

**Версия из Google Play заброшена и не обновляется — она не подойдёт.**
Ставьте с [F-Droid](https://f-droid.org/packages/com.termux/) или из
[релизов на GitHub](https://github.com/termux/termux-app/releases).

Если Termux из Google Play уже стоит — удалите его перед установкой, иначе
Android не даст поставить сборку с другой подписью.

## Шаг 2. Поставить инструменты

```bash
pkg update && pkg upgrade
pkg install clang make git
```

`clang` вместо `g++` — это нормально: `make` сам подхватит доступный
компилятор.

## Шаг 3. Собрать и запустить

```bash
git clone https://github.com/dpsmpx/Andors-Love.git
cd Andors-Love
git checkout claude/project-full-review-j9jx56
make
./andors-love
```

Запускать **из корня проекта** — карты ищутся по пути `data/maps/`.

Проверить, что всё собралось верно:

```bash
make test        # 287 проверок, должно быть «ВСЁ ЗЕЛЁНОЕ»
```

## Шаг 4. Настроить клавиши

Ходить можно на `WASD`, так что стрелки не нужны. Проблема одна — **Esc**
(пауза, сохранение, выход), которого нет на экранной клавиатуре.

Два способа:

- **Быстрый:** `Громкость вниз` + `E` — это и есть Esc в Termux.
- **Удобный:** добавить ряд дополнительных клавиш. Выполните один раз:

```bash
mkdir -p ~/.termux
cat > ~/.termux/termux.properties <<'EOF'
extra-keys = [ \
 ['ESC','1','2','3','?','UP','I'], \
 ['TAB','A','P','E','F','DOWN','Q'] \
]
EOF
termux-reload-settings
```

Появится два ряда кнопок прямо над клавиатурой: `ESC`, стойки `1 2 3`,
справка `?`, сумка `I`, квесты `Q` и боевые `A` (атака), `P` (мощный удар),
`E` (закончить ход), `F` (бежать). Если ряд не виден — проведите пальцем
вверх по клавиатуре.

## Шаг 5. Подогнать экран

Игра сама подстраивается под размер терминала: на широком экране панель
героя стоит справа от карты, на узком — уезжает под карту, а окно обзора
сжимается. Работает начиная примерно с 28 колонок.

Чтобы уместилось больше:

- **Уменьшить шрифт** — щипок двумя пальцами по экрану.
- **Повернуть телефон в альбом** — колонок станет заметно больше; при
  ширине от 80 колонок включается раскладка с боковой панелью.

Посмотреть текущий размер:

```bash
echo "${COLUMNS}x${LINES}"
```

## Сборка в C4Droid

C4Droid сам выставляет окружение под свой GCC. Проверьте, что компилятор виден:

```bash
g++ --version
```

Дальше из каталога проекта:

```bash
cd /sdcard/CODE/Cpp/Andors_Love
make
```

### Две ловушки, о которых стоит знать заранее

**1. Свой `CXXFLAGS` не должен уносить стандарт языка.** Если в окружении
задано, например, `export CXXFLAGS="-Os -s -pie"`, оно целиком заменяет флаги
из Makefile. Стандарт языка вынесен в отдельную переменную `CXXSTD` именно
поэтому — `-std=c++11` подставляется всегда, что бы ни лежало в `CXXFLAGS`.
Проверить можно по первой строке вывода `make`: в ней должен быть `-std=`.

Задать другой стандарт, если нужно:

```bash
make CXXSTD=-std=c++17
```

**2. С `/sdcard` нельзя запускать бинарники.** Этот раздел памяти почти всегда
смонтирован с флагом `noexec`, поэтому `./andors-love` прямо из папки проекта
обычно выдаёт `Permission denied`. Скопируйте собранный файл в приватный
каталог приложения и запускайте оттуда, **не уходя из папки проекта**:

```bash
BIN=/data/user/0/com.n0n3m4.droidc/files/andors-love
cp andors-love "$BIN" && chmod 755 "$BIN"
"$BIN"
```

Карты при этом найдутся: игра ищет `data/maps` относительно текущего каталога,
а он остался в проекте. Сохранения лягут туда же, в `saves/` рядом с исходниками.

Если удобнее запускать из произвольного места, укажите путь к данным явно:

```bash
export ANDORS_LOVE_DATA=/sdcard/CODE/Cpp/Andors_Love/data/maps
"$BIN"
```

Порядок поиска карт: переменная `ANDORS_LOVE_DATA`, затем `data/maps` в текущем
каталоге, затем `data/maps` рядом с самим бинарником.

### Ввод

Если консоль не даёт посимвольный ввод, игра это замечает и переходит в
построчный режим — тогда после каждой клавиши нужно нажимать Enter. Играть
можно, но в Termux удобнее.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| `make: g++: command not found` | Не установлен компилятор: `pkg install clang` |
| `не удалось открыть файл карты` | Запущено не из корня проекта: `cd ~/Andors-Love` |
| Строки переносятся и всё рябит | Слишком крупный шрифт: щипок для уменьшения, либо альбомная ориентация |
| Вместо букв кракозябры | `pkg install ncurses-utils` и убедитесь, что локаль UTF-8 (в Termux она такая по умолчанию) |
| Нажатия «залипают» или дублируются | Выключите автоподстановку и Т9 в настройках клавиатуры Android |
| Esc не срабатывает | `Громкость вниз` + `E`, либо настройте ряд из шага 4 |
| `fatal error: filesystem: No such file or directory` | Старая копия исходников. Возьмите свежую: в ней `<filesystem>` не используется |
| Ошибки вида `no match for 'operator='` на `{ {...} }` | В строке компиляции нет `-std=`. См. ловушку 1 в разделе про C4Droid |
| `./andors-love: Permission denied` | Запуск с `/sdcard` (`noexec`). См. ловушку 2 |
| `не удалось открыть файл карты` при запуске не из проекта | `export ANDORS_LOVE_DATA=/путь/к/data/maps` |

## Сохранения

Лежат в `saves/hero.sav` внутри папки проекта — это обычный текстовый файл.
Скопировать на компьютер:

```bash
pkg install termux-api        # один раз
termux-setup-storage          # разрешить доступ к памяти
cp saves/hero.sav ~/storage/downloads/
```

Файл переносим между телефоном и компьютером как есть: формат один и тот же.

## Обновиться до свежей версии

```bash
cd ~/Andors-Love
git pull
make
```
