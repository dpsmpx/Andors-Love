# Как играть со смартфона

Игра — обычное консольное приложение на C++, поэтому на Android ей нужен
только компилятор и терминал. Проще всего это даёт **Termux**.

## Чем собирать

Подходят оба варианта, разница в удобстве.

| | Termux | C4Droid |
|---|---|---|
| Сборка | `make`, как на компьютере | `make` из встроенной консоли |
| Компилятор | clang (свежий) | GCC из плагина (часто старый) |
| Запуск бинарника | откуда угодно | `/sdcard` смонтирован `noexec` — нужен обходной шаг |
| Обновление | `git pull` | копировать файлы вручную |

Коду достаточно **C++11**, так что старый GCC из C4Droid его собирает.
Ниже сначала Termux, потом C4Droid — раздел [«Сборка в C4Droid»](#сборка-в-c4droid).

## Шаг 1. Поставить Termux правильно

**Версия из Google Play заброшена и не обновляется — она не подойдёт.**
Ставьте с [F-Droid](https://f-droid.org/packages/com.termux/) или из
[релизов на GitHub](https://github.com/termux/termux-app/releases).

Если Termux из Google Play уже стоит — удалите его перед установкой, иначе
Android не даст поставить сборку с другой подписью.

## Шаг 2. Поставить инструменты

```bash
pkg update && pkg upgrade
pkg install clang make git
```

`clang` вместо `g++` — это нормально: `make` сам подхватит доступный
компилятор.

## Шаг 3. Собрать и запустить

```bash
git clone https://github.com/dpsmpx/Andors-Love.git
cd Andors-Love
git checkout claude/project-full-review-j9jx56
make
./andors-love
```

Запускать **из корня проекта** — карты ищутся по пути `data/maps/`.

Проверить, что всё собралось верно:

```bash
make test        # 287 проверок, должно быть «ВСЁ ЗЕЛЁНОЕ»
```

## Шаг 4. Настроить клавиши

**Escape игре не нужен.** Ходить — `WASD`, меню — `M`, назад из любого
списка — `Q` или `0`. Всё управление помещается в обычную экранную
клавиатуру: буквы, цифры, Enter и Backspace.

Ряд дополнительных клавиш всё же удобен — он даёт стрелки и боевые команды
под большой палец. Выполните один раз:

```bash
mkdir -p ~/.termux
cat > ~/.termux/termux.properties <<'EOF'
extra-keys = [ \
 ['ESC','1','2','3','?','UP','I'], \
 ['TAB','A','P','E','F','DOWN','Q'] \
]
EOF
termux-reload-settings
```

Появится два ряда кнопок прямо над клавиатурой: `ESC`, стойки `1 2 3`,
справка `?`, сумка `I`, квесты `Q` и боевые `A` (атака), `P` (мощный удар),
`E` (закончить ход), `F` (бежать). Если ряд не виден — проведите пальцем
вверх по клавиатуре.

## Шаг 5. Подогнать экран

Игра сама подстраивается под размер терминала: на широком экране панель
героя стоит справа от карты, на узком — уезжает под карту, а окно обзора
сжимается. Работает начиная примерно с 28 колонок.

Чтобы уместилось больше:

- **Уменьшить шрифт** — щипок двумя пальцами по экрану.
- **Повернуть телефон в альбом** — колонок станет заметно больше; при
  ширине от 80 колонок включается раскладка с боковой панелью.

Посмотреть текущий размер:

```bash
echo "${COLUMNS}x${LINES}"
```

## Сборка в C4Droid

C4Droid сам выставляет окружение под свой GCC. Проверьте, что компилятор виден:

```bash
g++ --version
```

Дальше из каталога проекта:

```bash
cd /sdcard/CODE/Cpp/Andors_Love
make
```

### Две ловушки, о которых стоит знать заранее

**1. Свой `CXXFLAGS` не должен уносить стандарт языка.** Если в окружении
задано, например, `export CXXFLAGS="-Os -s -pie"`, оно целиком заменяет флаги
из Makefile. Стандарт языка вынесен в отдельную переменную `CXXSTD` именно
поэтому — `-std=c++11` подставляется всегда, что бы ни лежало в `CXXFLAGS`.
Проверить можно по первой строке вывода `make`: в ней должен быть `-std=`.

Задать другой стандарт, если нужно:

```bash
make CXXSTD=-std=c++17
```

**2. С `/sdcard` нельзя запускать бинарники.** Этот раздел памяти почти всегда
смонтирован с флагом `noexec`, поэтому `./andors-love` прямо из папки проекта
обычно выдаёт `Permission denied`. Скопируйте собранный файл в приватный
каталог приложения и запускайте оттуда, **не уходя из папки проекта**:

```bash
BIN=/data/user/0/com.n0n3m4.droidc/files/andors-love
cp andors-love "$BIN" && chmod 755 "$BIN"
"$BIN"
```

Карты при этом найдутся: игра ищет `data/maps` относительно текущего каталога,
а он остался в проекте. Сохранения лягут туда же, в `saves/` рядом с исходниками.

Если удобнее запускать из произвольного места, укажите путь к данным явно:

```bash
export ANDORS_LOVE_DATA=/sdcard/CODE/Cpp/Andors_Love/data/maps
"$BIN"
```

Порядок поиска карт: переменная `ANDORS_LOVE_DATA`, затем `data/maps` в текущем
каталоге, затем `data/maps` рядом с самим бинарником.

### Ввод

Если консоль не даёт посимвольный ввод, игра это замечает и переходит в
построчный режим — тогда после каждой клавиши нужно нажимать Enter. Играть
можно, но в Termux удобнее.

Escape в C4Droid набирается как `Громкость вверх` + `E`, но игре он не нужен:
меню открывается по `M`, выход из списка — `Q` или `0`.

## Сборка APK в C4Droid

C4Droid умеет упаковать собранную программу в отдельное приложение. Для
консольной игры он кладёт в APK бинарник и запускает его во встроенном
эмуляторе терминала.

### Что для этого уже сделано в проекте

APK — это один упакованный файл, и обычно на нём спотыкаются именно данные:
каталога `data/maps` внутри пакета нет, а рабочий каталог часто недоступен для
записи. В проекте оба препятствия сняты:

- **Карты вшиты в бинарник** (`src/embedded_maps.cpp`). Игра сначала ищет
  файлы на диске, а если их нет — берёт встроенную копию. Проверено: игра
  полностью проходится, когда рядом нет ничего, кроме самого бинарника.
- **Каталог сохранений выбирается сам:** `$ANDORS_LOVE_SAVE`, затем `saves/`
  в рабочем каталоге, затем `$HOME/.andors-love`, затем `$TMPDIR/andors-love`.
  Используется первый, в который удаётся записать файл.
- **`-pie` доходит до линковки.** Android запускает только PIE-исполняемые
  файлы; флаг из `CXXFLAGS` теперь передаётся и на шаг компоновки.

Отдельно класть `data/` в APK не нужно. Если положите — игра предпочтёт файлы
с диска, это тоже рабочий вариант.

### Как заполнить окно «Export APK»

Ресурсы добавлять не нужно: игра самодостаточна, оба поля с папками
оставляйте пустыми.

| Поле | Что ставить | Почему |
|---|---|---|
| Export binary instead of APK | не отмечать | нужен именно APK |
| File name | `AndorsLove.apk` | **без апострофов, пробелов и скобок** — путь уходит в шелл-команды сборки |
| Package name | `com.dpsmpx.andorslove` | строчными буквами; менять потом нельзя без потери сохранений |
| Application title | `Andors Love` | апостроф в заголовке может сломать сборку ресурсов Android |
| Version number | `1` | целое, растёт с каждой публикацией |
| Version text | `1.0` | видит пользователь |
| App icon filename | `(default)` или `icon.png` | квадратный PNG в корне проекта, 512×512 достаточно |
| App resources folder | `(none)` | карты вшиты в бинарник, внешних данных нет |
| App custom APK overlay folder | `(none)` | нативных библиотек и доп. ассетов нет |

Про апострофы отдельно: в `Andor's Love` он опасен дважды — в **имени файла**
(путь подставляется в команды оболочки) и в **заголовке приложения**
(незаэкранированный апостроф в строковых ресурсах Android — классическая
ошибка сборки). Если сборка падает на этих полях, уберите апостроф; красивое
название с ним можно вернуть позже, когда APK будет собираться.

Про имя пакета: оно определяет, где Android держит приватные данные
приложения. Если поменять его после первой установки, система посчитает это
другим приложением — сохранения не перенесутся.

### Порядок действий

1. Соберите и убедитесь, что всё работает из консоли (раздел выше). APK имеет
   смысл собирать только с рабочего бинарника.
2. `COMPILE` → экспорт APK, заполните поля по таблице выше.
3. Соберите и установите получившийся APK.

### Если APK не появляется

C4Droid хранит настройки проекта в файле `.c4droid` рядом с исходниками. Там
есть строка `binary_fname` — имя файла, который C4Droid считает результатом
сборки. Наш `Makefile` делает `andors-love`, поэтому:

- либо укажите в настройках проекта имя `andors-love`;
- либо соберите под тем именем, которого ждёт C4Droid:

```bash
make BIN=result
```

Проверьте также, что сборка запускалась именно кнопкой C4Droid, а не только
вручную из консоли: APK создаётся его собственным шагом упаковки, а не
`make`. И посмотрите, куда C4Droid кладёт результат — это может быть его
рабочий каталог, а не папка проекта.

### О чём стоит знать заранее

- **Архитектура.** Судя по путям, ваш GCC собирает под `aarch64` — APK
  получится только для 64-битных устройств. Для старого телефона понадобится
  сборка под `armv7`.
- **Многофайловый проект.** C4Droid проще всего экспортирует то, что собрал
  сам. Если экспорт не подхватывает `Makefile`, соберите проект вручную
  (`make`) и укажите готовый бинарник как то, что нужно упаковать.
- **Размер экрана.** Встроенный терминал даёт свою ширину; игра
  подстраивается автоматически начиная примерно с 28 колонок.
- **Сохранения.** Каталог выбирается сам: `$ANDORS_LOVE_SAVE`, затем `saves/`
  в рабочем каталоге, затем `$HOME/.andors-love`, затем `saves/` рядом с самим
  бинарником, затем `$TMPDIR`. Внутри APK сработает один из последних —
  приватный каталог приложения. Чтобы забрать сохранения наружу, задайте
  `ANDORS_LOVE_SAVE=/sdcard/AndorsLove`.

Точные названия пунктов меню в разных версиях C4Droid отличаются — если
экспорт называется иначе, ориентируйтесь на смысл: консольное приложение,
готовый бинарник, имя пакета.

## Изменение карт

Карты лежат в `data/maps/*.map` и продублированы внутри бинарника. После
правки карты обновите вшитую копию:

```bash
make embed && make
```

Тесты специально сверяют копию с файлом и падают, если про `make embed`
забыли, — так что рассинхрон не уедет незамеченным. Цель `embed` нужна только
при правке карт и требует python3; на телефоне её запускать не обязательно.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| `make: g++: command not found` | Не установлен компилятор: `pkg install clang` |
| `не удалось открыть файл карты` | Запущено не из корня проекта: `cd ~/Andors-Love` |
| Строки переносятся и всё рябит | Слишком крупный шрифт: щипок для уменьшения, либо альбомная ориентация |
| Вместо букв кракозябры | `pkg install ncurses-utils` и убедитесь, что локаль UTF-8 (в Termux она такая по умолчанию) |
| Нажатия «залипают» или дублируются | Выключите автоподстановку и Т9 в настройках клавиатуры Android |
| Esc не срабатывает | Он и не нужен: меню — `M`, назад — `Q` или `0` |
| `fatal error: filesystem: No such file or directory` | Старая копия исходников. Возьмите свежую: в ней `<filesystem>` не используется |
| Ошибки вида `no match for 'operator='` на `{ {...} }` | В строке компиляции нет `-std=`. См. ловушку 1 в разделе про C4Droid |
| `./andors-love: Permission denied` | Запуск с `/sdcard` (`noexec`). См. ловушку 2 |
| `не удалось открыть файл карты` при запуске не из проекта | `export ANDORS_LOVE_DATA=/путь/к/data/maps` |

## Сохранения

Лежат в `saves/hero.sav` внутри папки проекта — это обычный текстовый файл.
Скопировать на компьютер:

```bash
pkg install termux-api        # один раз
termux-setup-storage          # разрешить доступ к памяти
cp saves/hero.sav ~/storage/downloads/
```

Файл переносим между телефоном и компьютером как есть: формат один и тот же.

## Обновиться до свежей версии

```bash
cd ~/Andors-Love
git pull
make
```
